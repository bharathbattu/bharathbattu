### Cognitive Twin System  
A memory-aware AI system that models user cognition and simulates real-world decision-making.  

- Builds persistent cognitive profiles from user interactions  
- Uses semantic memory (FAISS) to retrieve contextual history  
- Generates decisions based on behavioral patterns, not just prompts  
- Full-stack system built with FastAPI, React (TypeScript), and LLM APIs  

This project explores how AI can move from reactive chat to personalized decision intelligence.
